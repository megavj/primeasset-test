# 보험은 지금 · 1차 테스트 견본

주소: https://test.primeasset.info/bohumnow/

기존 `mockup-v2/`의 12개 화면, 흰색·회색 구분선과 코랄 포인트, 모바일 목록·본문·댓글 순서를 유지한 클릭형 견본입니다. 프라임에셋 공통 메뉴나 스크립트를 사용하지 않습니다.

모든 화면에 **테스트 견본 — 저장되지 않습니다**를 표시합니다. 회사명은 삼성생명·현대해상·한화생명·교보생명·DB손해보험·KB손해보험을 그대로 쓰고, 닉네임은 첫 글자와 고정 별표 3개로 표시합니다. 사람·글·댓글·리뷰·평점·활동 수치는 모두 창작 예시이며 실제 회사 평가가 아닙니다.

| 파일 | 화면과 동작 |
|---|---|
| `index.html` | 토픽 베스트·인기글·6개 채널 최신글 |
| `channels.html` | 채널 탐색·팔로우·분류 필터 |
| `channel.html?channel=career` | 채널별 5개 글·최신/인기·답변 대기 상태 |
| `post.html?id=career-1` | 고유 제목·본문·회사·댓글·AI 참고 답변·좋아요·북마크·공유 |
| `post-guest.html?id=career-1` | 같은 글의 방문자 화면·댓글 잠금·회원 화면 체험 |
| `company.html?company=samsung` | 6개 회사 선택·소개/리뷰/게시글/키워드·리뷰 작성 미리보기 |
| `browse.html?company=samsung&keyword=교육` | 키워드 글 목록·정렬·검색 연결 |
| `search.html?q=정산` | 30개 글·6개 회사·6개 채널 검색·분류·빈 상태 |
| `write.html` | 입력·공개 범위·미리보기·현재 화면의 등록 결과 |
| `join.html` | 가상 예시로 가입·인증 대기/보완/승인/반려 흐름 |
| `me.html` | 내 글·북마크·팔로우·알림·계정 설정 미리보기 |
| `admin.html` | 역할별 인증/신고/AI·발행/사용량/감사 처리 미리보기 |

채널 식별자는 `career`, `products`, `claims`, `marketing`, `ga`, `talk`입니다. 글 식별자는 각 채널에 `-1`부터 `-5`까지 붙습니다. 30개 글마다 별도 본문과 사람 댓글 2개, 작성자 답글 1개, 채널 주제에 맞춘 AI 참고 답변 예시를 제공합니다. 모든 초기 글에 사람 댓글이 있으므로 ‘답변 대기’ 필터는 빈 상태를 보여 줍니다.

눌러볼 순서:

1. 홈 → 채널 → 관심 채널 → 글 → 댓글, 좋아요·북마크·댓글 입력.
2. 방문자 글 → 가입·인증 → 가상 예시 채우기 → 승인 예시 → 원래 글로 돌아오기.
3. 보험사 리뷰 → 회사 바꾸기 → 리뷰·게시글·키워드 탭 → 검색.
4. 글쓰기 → 가상 예시 채우기 → 공개 범위 미리보기 → 확인 → 등록 미리보기.
5. 상단 내 정보 → 북마크·알림·설정 → 상단 관리자 → 업무 역할과 처리 화면.

좋아요·팔로우·북마크·댓글·작성 결과는 현재 문서의 메모리에만 남습니다. 새로고침하거나 다른 페이지로 이동하면 초기화됩니다. 쿠키·localStorage·sessionStorage·IndexedDB를 쓰지 않습니다. 가입·로그인·인증·DB·AI·외부 전송은 연결하지 않았습니다. 폼에는 실제 개인정보 대신 가상 예시를 사용하세요.

모든 HTML에 `noindex,nofollow`가 있고 사이트맵이나 검색 등록을 추가하지 않았습니다. 이미지·글꼴·스크립트는 외부에서 불러오지 않습니다. 시스템 글꼴, CSS 문자 타일과 공통 JS의 인라인 SVG 아이콘만 사용합니다.

구현은 12개 HTML과 `style.css`, `app.js`, `data.js`, `demo.js`입니다. 정적 파일을 열거나 같은 경로 구조로 웹서버에서 제공하면 됩니다. QA 기록과 스크린샷은 작업폴더의 `evidence-im/`에 보관하며 사이트에는 배포하지 않습니다.
