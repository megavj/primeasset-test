섹션 2

구글 계정으로 로그인

버튼 하나로 로그인. 처음이면 바로 가입 신청.

섹션 3

이메일 인증 로그인

이메일 주소 입력 → 인증 메일의 링크를 눌러 로그인.

섹션 4

가입 정보 입력 + 개인정보 동의

처음 로그인한 분만: 이름·소속 본부·휴대폰, [필수] 개인정보 수집·이용 동의(방침 링크).

섹션 5

가입 후 순서

① 로그인 → ② 가입 정보 입력 → ③ 관리자 승인 → ④ 등급에 맞는 도구 열림.
