03 / 설계사를 위한 환경

조건은 공개하고,
영업은 지원합니다.

규정·수수료는 공개하고, 자료·교육은 지원합니다.

공개된 운영 원칙

  • 초대형 GA, 1만여 명 설계사가 근무하는 독립법인
  • 영업규정집 공개: 위촉·해촉, 승격·분할, 수수료, 준법 규정
  • 수수료: 본사가 설계사에게 직접 지급, 매달 수수료표·시책 공개, 팜스에서 계약별 수수료 역추적
  • 승격: 설계사 → 팀장 → 지사장 → 본부장, 규정 충족 시 자동 승격
  • 본사 지원: 조직도·담당 연락처 공개, 직급별·테마별·온라인 교육

자세한 규정·수수료·승격 기준·교육 자료는 로그인 후 인트라넷 '프리미엄 안내 자료'에 있습니다.

설계사 성장 시스템

  • 자료 수천 건 자료를 한 번에 찾는 통합 자료검색기
  • 콘텐츠 최신 보험뉴스·상품비교·소식지 분석 도구
  • AI 화법·상담·DB영업을 돕는 AI 영업비서
  • 교육 스탠다드 캠퍼스 · 표준 영업 매뉴얼 체계
  • 운영 수수료·규정·시책을 투명하게 공개하는 운영 구조

04 / 사람과 일하는 방식

김상현 이사 소개

말보다 데이터와 시스템으로 일하는 보험영업가

프라임에셋 188본부 본부장 · 프리미엄사업부

프라임에셋 이사, 프리미엄사업부 대표. 2017년 3월 188본부 승격, 2021·2022년 MVP 2년 연속 선정, 2021년 명예이사 직급 달성. (소개 자료 원문: 기존 사이트)

2009년 현장에서 시작했습니다. 이제 설계사가 성과를 내는 영업 환경을 만듭니다.

현장에서 직접 검증한 방식만 시스템으로 옮깁니다. 말로 설득하기보다 조건·수수료·규정을 그대로 공개하고, 직접 비교해 판단하도록 합니다.

걸어온 길

  1. 2009.10 PCA생명에서 보험 영업 시작
  2. 2012 교보생명·교보생명 전속대리점을 거쳐 프라임에셋 입사 (보험설계사)
  3. 2017.3 본부장 승격 · 온라인영업 특화 188본부 출범
  4. 2021.1 MVP · 명예이사 · 프리미엄사업부 수장
  5. 2026~ AI·자동화 기반 설계사 지원 시스템 구축

일하는 방식

  • 정직·직설 — 문서와 수치로 말합니다.
  • 사람 중심 — 사람이 먼저인 시스템을 만듭니다.
  • 데이터 우선 — 근거로 판단합니다.
  • 본질과 결과 — 현장에서 검증합니다.

출처: 기존 사이트 '김상현 이사를 소개합니다' 소개 화면 글.

05 / 방향과 목표

설계사의 성공이
조직의 성공입니다.

함께 성장하는 환경을 만듭니다.

  1. 자료 공유 — 보험·영업자료를 체계적으로 정리하고 본부카페·단톡방으로 빠르게 나눕니다.
  2. 전문가 육성 — 보상·온라인영업 교육을 매뉴얼로 만들고 분야별 전문가를 키웁니다.
  3. 설계사 성장 지원 — 설계사의 성공과 산하 조직의 만족을 우선합니다. 관리자 규정을 공개해 누구나 도전할 수 있게 합니다.
  4. 지역과 영업채널 확장 — 전국 86개 시도별 지점을 목표로 합니다. 현재 전국 사무실은 CY'25 기준 62개입니다. 10년·20년 성장을 위해 영업채널을 넓힙니다.
  5. 효율적인 영업 지원 — 트렌드에 맞는 새 방식을 경험·공유하고, 익숙한 방식도 다시 살핍니다.
  6. 바른 영업 — 불법·불완전판매를 지양합니다. 본부장·지점장이 먼저 뛰며 다른 회사·조직의 모범을 지향합니다.
